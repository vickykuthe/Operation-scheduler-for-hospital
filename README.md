# 🏥 Operation Scheduler for Hospital
# Vicky kuthe (👨‍💻 web developer)

## 📌 Overview
A web app to automate surgery scheduling.  
Assigns doctors to OTs based on availability, preferences, and emergencies.  
Built with HTML, CSS, JS, and Firebase.

## 🎯 Objective
Replace manual OT schedules with a smart, dynamic system.  
Improve efficiency, reduce conflicts, and support emergencies.

## ⚙️ Tech Stack
- HTML, CSS, JavaScript  
- Firebase (Auth + Database)

## 🔑 Features
- Dynamic doctor & OT assignment  
- Admin and User dashboards  
- Real-time updates  
- Emergency case handling  
- Secure login and action logs  
- Mobile-friendly
